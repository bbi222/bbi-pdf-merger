# bbi PDF Merger

Merge multiple PDF files into one, right in your browser.
**Your files never leave your device.** No upload, no sign-up, no install.

👉 **Try it:** https://bbi222.github.io/bbi-pdf-merger/

## Features
- Merge many PDFs into a single file
- Choose page ranges per file (e.g. `1-3, 5`)
- Reorder files, sort, remove, and preview
- Drag & drop supported
- Works on desktop and mobile
- English / Korean (auto-detected, switch with KR | EN)

## Privacy
Everything runs locally in your browser. Files are never uploaded to any server.

## Built with
- Single-file HTML, no build step
- [pdf-lib](https://github.com/Hopding/pdf-lib) (MIT License)

# bbi PDF 병합기

여러 PDF 파일을 브라우저에서 바로 하나로 합쳐요.
**파일은 내 기기 밖으로 나가지 않아요.** 업로드, 가입, 설치가 필요 없어요.

👉 **바로 쓰기:** https://bbi222.github.io/bbi-pdf-merger/

## 기능
- 여러 PDF를 하나로 합치기
- 파일별 페이지 범위 지정 (예: `1-3, 5`)
- 순서 바꾸기, 정렬, 삭제, 미리보기
- 끌어다 놓기 지원
- PC와 모바일 모두 사용 가능
- 한국어 / English (자동 선택, KR | EN 버튼)

## 개인정보
모든 처리는 내 브라우저 안에서만 이루어져요. 파일은 어떤 서버로도 올라가지 않아요.

## 사용한 것
- 빌드 과정 없는 단일 HTML 파일
- [pdf-lib](https://github.com/Hopding/pdf-lib) (MIT 라이선스)
